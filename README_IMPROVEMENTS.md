# 选科系统改进说明

## 新增功能

### 1. 开发者工具 🛠️
- **快捷键**: Ctrl+Shift+D 快速打开/关闭
- **功能包括**:
  - 实时查看测试数据
  - 导出JSON格式数据
  - 测试AI连接状态
  - 清空测试数据
  - 原始数据查看器

### 2. 增强AI功能 🤖
- **真正的DeepSeek API集成**
- **改进的对话系统**:
  - 上下文记忆功能
  - 个性化建议生成
  - 更智能的错误处理
  - 清空对话历史功能

### 3. 用户体验改进
- **改进的AI聊天界面**:
  - 支持多行输入
  - Ctrl+Enter快捷发送
  - 更好的加载状态显示
- **开发者入口按钮**:
  - 右下角固定按钮
  - 实时数据更新

## 使用方法

### 开发者工具
1. 点击右下角🛠️按钮或按Ctrl+Shift+D
2. 查看实时测试进度和数据
3. 使用导出功能保存数据
4. 测试AI连接状态

### AI聊天
1. 完成测试后点击"获取AI个性化分析建议"
2. AI会基于测试结果提供详细建议
3. 可在对话框中继续提问
4. 使用"清空对话"按钮重新开始
