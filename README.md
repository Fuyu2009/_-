
选科是高中生学习生涯的重要节点，直接关系到学生自身的未来职业规划和终身发展。在3+1+2高考模式的实际选科过程中，部分学生因不知如何结合“自身优势和兴趣”“未来专业职业规划和需求”与“相关政策变动”等个人与外界因素后作出最有利于自己的选科，而陷入盲目决策的困境。因此，本研究尝试搭建一个选科决策辅助网站。基于此目的，我成员以田园调查、问卷的形式了解了我校学生的选科情况、选科过程中面临的困难与与对已有的选课指导的评价。对调查结果进行分析后，我成员构思在网站中 着重于以测试的形式引导学生从“兴趣”“气质”“性格”“能力”“职业价值观”五个方面 建立客观自我认识，做出初步的职业生涯规划，在此基础上符合自身的选科决策。
